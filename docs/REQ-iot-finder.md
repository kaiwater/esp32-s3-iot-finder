# 需求：ESP32-S3 IoT Finder（MAC + RSSI 热冷法）

> 项目：`esp32-s3-iot-finder`
> 硬件：ESP32-S3 + ST7735 160x128 + 4 键 + 可选 NRF24L01
> 定位方式：被动 Wi-Fi 嗅探，锁定单个 MAC，用每帧 RSSI 做热冷逼近

---

## 1. 背景与目标

现场有一批智能插座 / IoT 设备需要复位换绑，但不知道每个物理位置。
需要一台手持设备：

- 锁定目标设备的 MAC
- 看它相对本机的信号强弱（越近越强）
- 举着走，靠热冷反馈逼近到具体房间
- 找到后回路由器换绑

**成功标准**：目标处于配网/探针状态时，10 分钟内定位一只，误差约 ±1 米。

## 2. 能力边界

| 手段 | 能给 | 不能给 |
|---|---|---|
| ESP32 Wi-Fi sniffer | 每帧 RSSI、MAC、帧类型、信道、速率 | 5GHz、80MHz、MIMO 帧内容 |
| NRF24L01 RPD | 1-bit「>-64dBm」、1MHz 步进 | 任何 dBm、MAC 识别 |
| 单根全向天线 | 远近 | 方向 |

结论：

- 定位只能用 Wi-Fi sniffer，nRF 认不出是哪个设备
- nRF 是辅助：目标静默时告诉你「这儿有能量」
- 方向测不了，只能热冷法 + 人走

## 3. 目标 MAC

1. **串口输入**：`mac AA:BB:CC:DD:EE:FF`
2. **学习模式**：长按 K2 后 5 秒，取信号最强 / 帧数最多的未知 STA
3. **列表选择**：短按 K3，在最近 60 秒出现的 STA 里循环

持久化到 NVS，重启不丢，支持清除。只在目标变化时写 flash。

## 4. 信道

- 默认 1-13 轮询，每信道 150ms
- 听到目标后自动锁定到目标信道
- 短按 K1 锁定/解锁；长按 K1 手动切下一信道
- 国家码设置为 1-13，避免 12/13 被禁用

## 5. 实时指标

| 指标 | 说明 |
|---|---|
| RSSI | `rx_ctrl.rssi`，最近 5 帧中位数 |
| RSSI 条 | -95..-25 映射 0..100% |
| 峰值保持 | 本次会话最高，可一键清零 |
| 帧率 | 每秒匹配帧数，1 秒窗口 + 4 点滑动平均 |
| 最近出现 | 距最后一帧的毫秒数 |
| 关联信息 | 目标所在 BSSID / SSID / 信道 |
| 厂商 | OUI 查询；本地管理地址显示 LOCAL ADMIN |

## 6. 热冷反馈

RSSI 越高，数字和进度条越偏绿；越弱越偏黄/橙/红：

| RSSI | 标签 |
|---|---|
| > -45 | HOT |
| -45 ~ -60 | WARM |
| -60 ~ -75 | COOL |
| < -75 | COLD |

无蜂鸣器，使用屏幕颜色 + 进度条 + 大字数值。

## 7. 状态机

- `SEEN`：< 5 秒内有帧
- `WEAK`：5~30 秒
- `LOST`：> 30 秒

## 8. UI 布局（160x128）

```text
┌────────────────────────┐
│ IOT FIND          2.4G │
│ A4:C1:38:xx:xx:xx LOCK │
│ Espressif        CH 6  │
│ RSSI                   │
│      -52 dBm      HOT  │
│ ███████████████░░  78% │
│ PEAK -41        FPS 12 │
│ LAST 0.3s        SEEN  │
│ BSSID A4:C1:38:...     │
│ SSID  Home_2.4G        │
│ CH 6 LOCK  CAND 4  RF42│
│ K1 LOCK K2 LEARN K3... │
│ K3 HOLD CLEAR  K4 INFO │
└────────────────────────┘
```

按键：

| 键 | 短按 | 长按 |
|---|---|---|
| K1 | 锁定/解锁信道 | 下一信道（手动锁定） |
| K2 | 峰值清零 | 重新学习目标 |
| K3 | 下一个候选 | 清除目标 |
| K4 | FINDER / INFO 页 | 重启 |

## 9. 技术实现要点

1. `esp_wifi_set_promiscuous(true)` + `esp_wifi_set_promiscuous_filter()`
   filter = `MGMT | DATA | CTRL`
2. 回调里只做 MAC 匹配 + 入队；解析、平滑、UI 全放主任务
3. 匹配 `addr1/addr2/addr3`，4 地址数据帧也看 `addr4`
4. 只在软件层按 MAC 过滤
5. 帧率 1 秒窗口 + 4 点滑动平均
6. 显示刷新 10Hz
7. **不要用 `esp_wifi_scan`**，不发 probe request
8. 目标在 5GHz 时 ESP32 听不到

## 10. 验收标准

1. 插座复位进配网后，3 秒内锁定到它的 probe request
2. 1m / 5m / 10m 三处 RSSI 有明显阶梯
3. 隔一堵墙下降 10~15dB
4. 目标静默 30 秒内进入 `LOST`
5. 连续跑 30 分钟不崩、不丢目标
6. 目标 MAC 断电重启后仍在

## 11. 非目标

- 不做三角/测距/成像
- 不做 5GHz
- 不做主动探测
- 不识别 2.4G 图传协议 / 无人机型号
